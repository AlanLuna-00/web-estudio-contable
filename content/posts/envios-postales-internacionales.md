## Nuevas reglas para los envíos postales internacionales

ARCA introdujo importantes modificaciones en el régimen de **envíos postales internacionales**, tanto para las compras provenientes del exterior destinadas a uso personal como para las exportaciones con finalidad comercial.

Las nuevas disposiciones buscan simplificar los procedimientos aduaneros y agilizar las operaciones realizadas por esta modalidad.

![Nuevas reglas para los envíos postales internacionales](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcSH8LWK6ZHlBmt70UVtd1tP9ptqUA1uesbnQTLOnlY2og&s=10)

### Importaciones para uso personal

La **Resolución General ARCA 5884/2026** actualizó las condiciones aplicables a los envíos internacionales que ingresan al país mediante el operador postal designado, incluido el servicio **puerta a puerta**.

Para acceder al régimen simplificado, los envíos deben cumplir con las siguientes condiciones:

- Tener un valor máximo de **USD 3.000 FOB por envío**.
- Estar destinados al **uso o consumo personal**.
- Incluir hasta **3 unidades de la misma especie**.
- No presumir **finalidad comercial**.

Además, el nuevo procedimiento permite adelantar determinadas gestiones antes de que el paquete llegue al país, facilitando el despacho de los envíos una vez arribados.

### Exportaciones comerciales sin límite de valor

Uno de los cambios más importantes se produjo para las **exportaciones con finalidad comercial realizadas por vía postal**.

La nueva normativa eliminó el límite de valor para estas operaciones, ampliando las posibilidades de utilizar esta modalidad para realizar ventas al exterior.

| Operación | Principales condiciones |
| --------- | ----------------------- |
| Importación para uso personal | Hasta USD 3.000 FOB por envío |
| Cantidad de unidades | Hasta 3 unidades de la misma especie |
| Finalidad de la importación | Uso o consumo personal, sin finalidad comercial |
| Exportación comercial por vía postal | Sin límite de valor |

Esta modificación puede resultar especialmente relevante para **emprendedores, PyMEs y pequeños exportadores** que utilizan los servicios postales para comercializar sus productos en mercados internacionales.

![Envíos internacionales y operaciones de comercio exterior](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcSLR2A7vSU0z78unGLnB5rfHwDMqL42hFN_juqgHWt1dA&s=10)

### Procedimiento simplificado para exportaciones

A través de la **Resolución General ARCA 5886/2026**, se estableció un procedimiento de **declaración simplificada** para las exportaciones de mercaderías con finalidad comercial realizadas por vía postal mediante el operador postal designado.

El objetivo es reducir la carga administrativa y facilitar este tipo de operaciones.

Sin embargo, existen mercaderías que no pueden utilizar este procedimiento simplificado. Entre ellas se encuentran determinados bienes sujetos a tratamientos específicos de control aduanero, cupos de exportación o intervenciones particulares de otros organismos.

Por eso, antes de realizar una operación es importante verificar si la mercadería puede ser enviada utilizando este régimen.

### ¿Qué cambia para quienes realizan envíos internacionales?

Las modificaciones buscan establecer procedimientos más ágiles tanto para quienes compran productos en el exterior como para quienes comercializan productos argentinos internacionalmente.

En el caso de las **importaciones personales**, se actualizan las condiciones del servicio puerta a puerta y se establece el límite de **USD 3.000 FOB**.

Para las **exportaciones comerciales**, la eliminación del límite de valor y la implementación de una declaración simplificada amplían las posibilidades de utilizar la vía postal como canal para llegar a clientes del exterior.
